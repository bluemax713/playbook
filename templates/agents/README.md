# Agents in This Repo

> How outside agents (anything that is not this repo's Claude Code session) work here without colliding with Claude Code or each other.
> Shared rules, identical in every repo that uses this pattern. Agent-specific rules live in `agents/<name>/instructions.md`.
> Managed by the Playbook (`/agent-setup`). Outside agents do not edit this file.

## Layout

```
WORK_LOG.md                  Claude Code's log (only Claude Code writes it)
agents/
  README.md                  this file: the shared rules
  <name>/
    LOG.md                   that agent's log (only that agent writes it)
    instructions.md          that agent's rules for THIS repo
```

The agents working here are the folders under `agents/` (every `agents/*/LOG.md`). Names are lowercase, one word (e.g. `duet`). Claude Code's name is `claude-code`.

## Before any work

1. Read this file, `CLAUDE.md` (project rules), and your own `agents/<name>/instructions.md`.
2. Read the top of `WORK_LOG.md` and of every `agents/*/LOG.md`: latest entry, **Handoffs** block, **Claimed** list.
3. Pick up any items addressed to you (`→ <your name>:`) and note the pickup in your own log.

## The four rules

1. **Claim before working.** Before starting a task, claim it so no one else picks it up:
   - **With a PM tool** (ClickUp, Linear, etc.): tag the task with your name (`<name>`, `claude-code`) and move it to in progress. Never work a task tagged for someone else.
   - **Without a PM tool:** add a line under **Claimed** at the top of your log (`- <task> (since YYYY-MM-DD)`). Check every other log's Claimed list first. Remove the line when done.
2. **One writer per production system at a time.** Anyone may read production systems. Writes happen only through a claimed task, and only within what that agent's `instructions.md` allows.
3. **Separate logs.** Each agent writes only its own log; Claude Code writes only `WORK_LOG.md`. Everyone reads every log. Newest entries at top, dated headings.
4. **Explicit handoffs.** Each log has a **Handoffs** block at the top. Address items to the receiver by name (`→ Claude Code:`, `→ Duet:`; the name matches the agent's folder, case doesn't matter) with enough context to act cold (task link, PR link, what was verified). The receiver notes pickup in its own log; the log's owner then removes the item.

## Git

- Outside agents work on `<name>/<topic>` branches and open PRs. Never push to main.
- Outside agents never edit `CLAUDE.md`, `WORK_LOG.md`, this file, their own `instructions.md`, or another agent's folder.
- Claude Code reviews and merges outside agents' PRs. If a PR needs changes, Claude Code leaves review comments plus a `→ <name>:` handoff in `WORK_LOG.md`.

## Multi-repo work

If one task touches several repos, log it in **each** repo you changed, in that repo's `agents/<name>/LOG.md`. Never log work for repo A in repo B.

## Secrets

Never print tokens, passwords, or other secrets in logs, handoffs, PRs, or commits. Logs are committed to git.
